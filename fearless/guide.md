# C팀 LoL 내전 밴픽 위키

[추정] **레오나·렐과 징크스·야스오·제이스·녹턴까지 표적 밴을 받을 수 있다.** 1세트 기본은 **제이스 / 녹턴 / 사일러스 / 징크스 / 노틸러스**다. 제이스는 암베사, 녹턴은 세주아니, 징크스는 케이틀린이 첫 대안이다. 야스오가 막히면 후속 세트 미드는 요네 또는 효준의 마법 피해 챔피언으로 바꾼다.

# C팀 포지션과 세트별 조합

[추정] 기본 배치는 **탑가는 경문이 탑 · 검은살치살 정글 · 효준 미드 · DevJoon 원딜 · mqz 서폿**이다. 야스오·요네 조합에서는 **DevJoon 미드 · 효준 원딜**로 바꾼다. 대회에서 효준은 정글을 맡지 않으므로 세주아니를 쓸 때도 검은살치살이 정글을 맡는다.

| 세트 | 조합 순서 탑 / 정글 / 미드 / 원딜 / 서폿 | 교전 계획 |
| --- | --- | --- |
| 1세트 | 제이스 / 녹턴 / 사일러스 / 징크스 / 노틸러스 | 제이스로 먼저 체력을 깎고 노틸러스가 연 대상에 녹턴이 합류한다. 징크스가 바로 공격할 수 있는 거리에서 시작한다. |
| 2세트 | 암베사 / 세주아니 / 빅토르 / 케이틀린 / 쓰레쉬 | 빅토르와 케이틀린이 입구를 막는다. 세주아니가 먼저 열거나 쓰레쉬가 끌어온 대상에게 덫을 잇는다. |
| 3세트 | 올라프 / 오공 / 야스오 / 미스 포츈 / 룰루 | DevJoon이 야스오, 효준이 미스 포츈. 오공이 띄운 적에게 궁을 잇고 룰루는 진입을 받은 아군을 살린다. |

[추정] 2세트 쓰레쉬가 소모됐으면 룰루, 세주아니가 빠졌으면 오공을 쓴다. 빅토르가 빠졌을 때는 오리아나가 후보며, 효준의 내전 미드 기록은 각각 1경기라 둘 다 연습 우선이다. 3세트 오공이 빠졌으면 리 신, 미스 포츈이 빠졌으면 카이사, 룰루가 빠졌으면 라칸을 본다. 리 신으로 바꾸면 야스오가 이을 수 있는 각을 콜하고, 상대가 방어력을 많이 올릴 조합이면 두 카드가 열린 경우 효준 에코·DevJoon 베인도 검토한다.

# 블루와 레드 선픽

[추정] 아래 순서는 토너먼트 드래프트 기준이다. B1은 블루 첫 픽, R5는 레드 마지막 픽이다. 같은 포지션의 주력 카드가 줄어들면 남은 카드를 앞당겨 확보한다.

| 세트 | 블루 | 레드 |
| --- | --- | --- |
| 1세트 | B1 노틸러스, B2·B3 징크스·녹턴이 기본. 서폿 후보가 여럿 남고 정글 후보가 한 장이면 정글을 B1로 올린다. | R1·R2 노틸러스·징크스, R3 녹턴이 기본. 정글 대체가 한 장이면 R1·R2로 올리고 서폿 또는 원딜을 R3에 잡는다. 탑을 늦게 열 수 있으면 R5를 매치업에 쓴다. |
| 2세트 | B1 세주아니, B2·B3 케이틀린·쓰레쉬. 쓰레쉬가 상대와 겹치고 정글 여유가 있으면 쓰레쉬를 B1로 올린다. | R1·R2 케이틀린·쓰레쉬, R3 세주아니. 상대가 정글을 먼저 가져갈 가능성이 높으면 R1·R2로 세주아니를 당긴다. |
| 3세트 | B1 오공, B2·B3 야스오·미스 포츈. 오공이 없으면 남은 띄우기 카드와 야스오를 묶을 수 있는지 먼저 확인한다. | R1·R2 오공·미스 포츈, R3 야스오 또는 남은 서폿. 상대 미드가 야스오에 불리한 매치업을 만들 수 있다면 미드를 R5까지 보류한다. |

## 상대가 먼저 픽했을 때

[추정] 아래는 **우리 레드**에서 다른 축이 열려 있을 때의 우선순위다. R1·R2를 잠그면 상대가 B2·B3를 연속으로 고른다. R3 후보의 백업까지 정한 뒤 첫 두 픽을 확정한다.

| 상대 B1 | 우리 R1·R2 | 다음 픽에서 볼 것 |
| --- | --- | --- |
| 노틸러스 | 징크스 · 세주아니 | 레오나·렐이 막혀 있다면 R3 룰루. 룰루 선점이 더 급하고 정글 여유가 있으면 R2 룰루·R3 세주아니. |
| 레오나 | 노틸러스 · 징크스 | R3 녹턴. 상대가 녹턴을 가져가면 세주아니. |
| 징크스 | 노틸러스 · 케이틀린 | R3 녹턴. 상대가 B2·B3에서 녹턴도 가져가면 세주아니. |
| 녹턴 | 세주아니 · 노틸러스 | R3 징크스. 상대가 징크스도 가져가면 케이틀린. |
| 제이스 | 노틸러스 · 징크스 | 제이스 포지션이 확인되면 R5 탑에서 열린 암베사·올라프 등 매치업을 비교. |
| 야스오 | 노틸러스 · 징크스 | 1세트는 그대로 진행. 3세트는 DevJoon 요네 또는 효준 미드로 전환. |

[추정] **우리 블루**는 B1 노틸러스를 잠근 뒤 상대 R1·R2를 보고 B2·B3를 묶어서 정한다. 상대가 녹턴·징크스를 모두 가져가면 **세주아니·케이틀린**, 징크스만 가져가면 **케이틀린·녹턴**, 녹턴만 가져가면 **징크스·세주아니**를 본다. 상대 픽 순서만으로 포지션을 확정하지 않는다.

[추정] **2차 이후**에는 현재까지 밴·픽된 후보를 뺀다. 블루 B4·B5 뒤에는 상대 R5가 남는다. 레드는 R4에서 미드 등 급한 포지션을 채우고, 상대 탑을 볼 수 있다면 R5를 탑 매치업에 쓴다.

# 표적 밴 대응

[추정] 현재 화면에서 **밴됐거나 상대가 픽했거나 이전 세트에 소모된 챔피언**은 모두 불가로 본다. 토너먼트 드래프트는 상대가 1차에 3장만 밴하므로, 2차 밴이 걱정되는 포지션은 우리 첫 세 픽 안에 잡는다. 상대 밴은 세트당 5장이다. 레오나·렐과 징크스·야스오·제이스·녹턴이 첫 세트에 모두 막히려면, 적어도 하나는 상대 선점이나 우리 밴 등 다른 경로로 빠져야 한다.

## 1세트 제이스 녹턴 징크스 대응

[추정] 아래 칸은 **탑 / 정글 / 원딜** 순서다. 미드는 효준 사일러스, 서폿은 mqz 노틸러스가 기본이다. 야스오가 함께 막힌 경우에도 이 표를 그대로 쓰고 다음 항목에서 2·3세트 미드를 바꾼다.

| 제이스·녹턴 상태 | 징크스 가능 | 징크스 불가 |
| --- | --- | --- |
| 둘 다 가능 | 제이스 / 녹턴 / 징크스 | 제이스 / 녹턴 / 케이틀린 |
| 제이스만 불가 | 암베사 / 녹턴 / 징크스 | 암베사 / 녹턴 / 케이틀린 |
| 녹턴만 불가 | 제이스 / 세주아니 / 징크스 | 제이스 / 세주아니 / 케이틀린 |
| 둘 다 불가 | 암베사 / 세주아니 / 징크스 | 암베사 / 세주아니 / 케이틀린 |

[추정] 암베사까지 막히면 근접 상대에는 올라프, 그 외에는 갱플랭크나 잭스를 매치업으로 본다. 세주아니까지 막히면 오공, 오공도 막히면 리 신을 확인한다. 케이틀린까지 막히면 DevJoon 베인은 앞라인을 오래 때릴 수 있을 때, 이즈리얼은 상대 사거리와 진입이 부담스러울 때 본다. 베인·이즈리얼까지 막히면 스몰더 또는 **DevJoon 미드 / 효준 미스 포츈·카이사**를 검토한다. D전에서 우리 밴으로 이즈리얼을 소모할 수 있으니 미리 체크한다.

내전 기록은 탑가는 경문이의 탑 제이스 13경기·암베사 6경기, 검은살치살의 정글 녹턴 12경기·세주아니 3경기, DevJoon의 원딜 징크스 13경기·케이틀린 10경기와 미드 야스오 12경기·요네 9경기다.

## 야스오와 요네 대응

[추정] **야스오만 불가**면 3세트 DevJoon 요네·효준 미스 포츈 또는 카이사로 이어간다. **야스오·요네 모두 불가**면 효준이 미드에 남아 사일러스·빅토르·오리아나·에코 중 열려 있는 카드를 고르고, DevJoon이 남은 원딜을 맡는다. DevJoon의 이렐리아 미드도 3경기 기록이 있어 상대 미드가 먼저 보이고 우리 조합에 마법 피해가 있을 때 후보로 둔다.

[추정] 야스오가 열려 있고 오공 등 띄우기와 효준 원딜을 같이 확보할 수 있다면 1차 픽으로 당길 수 있다. 이때 다음 세트에서 요네나 효준 미드로 전환할 카드도 확인한다. 오공이 먼저 교전을 열 때는 미스 포츈이 따라갈 수 있는 사거리에서 들어간다. [라이엇 야스오 스킬](https://www.leagueoflegends.com/ko-kr/champions/yasuo/) · [라이엇 오공 스킬](https://www.leagueoflegends.com/ko-kr/champions/wukong/)

## 서폿 밴이 겹칠 때

[추정] 남아 있는 서폿과 정글을 같이 본다. 레오나가 열려 있고 상대도 가져갈 가능성이 크면 노틸러스 대신 첫 픽에 올릴 수 있다.

| 상황 | 블루와 레드 대응 |
| --- | --- |
| 레오나·렐 불가, 노틸러스 가능 | 정글이 급하지 않으면 블루 B1 또는 레드 R1·R2로 노틸러스를 잡는다. |
| 노틸러스도 불가 | 알리스타 또는 쓰레쉬를 첫 세 픽 안에 잡는다. 케이틀린 덫 연계와 랜턴이 필요하면 쓰레쉬, 먼저 열거나 들어오는 적을 밀어낼 수단이 필요하면 알리스타를 본다. |
| 알리스타·쓰레쉬까지 불가 | 세주아니·오공 중 가능한 앞라인을 먼저 확보한다. 룰루는 원딜 보호, 라칸은 합류 후 진입, 카르마는 거리 유지가 필요한 조합에 쓴다. |
| 레드에서 상대 B1 노틸러스 | 레오나도 없고 징크스가 열렸으면 R1·R2 징크스·세주아니, R3 룰루를 먼저 본다. 정글에 여유가 있고 룰루 선점이 더 급하면 R2 룰루·R3 세주아니로 바꾼다. 징크스도 없으면 케이틀린을 기준으로 다시 고른다. |

[추정] 세주아니·룰루 조합이면 **“세주가 열고 룰루는 원딜 쪽”**으로 콜을 맞춘다. 원딜이 바로 때릴 수 없으면 첫 진입을 미루고 룰루는 상대 다이브에 스킬을 남긴다.

# A팀 B팀 D팀 상대 밴

[추정] 1세트 우선순위다. 2차에는 상대가 아직 확정하지 않은 포지션을 노리고, 이미 픽·밴된 챔피언은 건너뛴다. 역할이 바뀌면 해당 선수의 실제 사용 챔피언으로 밴을 조정한다.

| 상대 | 1차 밴 | 2차 밴 |
| --- | --- | --- |
| A팀 · 우리 블루 | 스웨인 · 자크 · 말파이트 | 잔나 · 릴리아 |
| A팀 · 우리 레드 | 스웨인 · 자크 · 잔나 | 말파이트 · 릴리아 |

# 피어리스 규칙과 세트 사이 체크

**3전 2선승 무자비 피어리스.** 양 팀이 한 세트에서 밴한 10개와 픽한 10개가 같은 시리즈의 다음 세트부터 모두 금지된다. 2세트 시작 전에 20개, 3세트 시작 전에 40개가 이미 빠져 있다. 다음 상대와 새 시리즈를 시작하면 초기화한다.

[불확실] 대회의 토너먼트 드래프트 적용 여부는 운영진 확인 전이다. 적용 시 팀당 **3밴 → 3픽 → 2밴 → 2픽**이며, 양 팀 픽 순서는 **B1 → R1·R2 → B2·B3 → R3 / 2차 밴 / R4 → B4·B5 → R5**다. 동시 5밴으로 확정되면 위 표의 1·2차 후보를 픽 전에 합쳐 고른다. [라이엇 토너먼트 드래프트 규칙](https://www.leagueoflegends.com/en-sg/news/dev/dev-the-return-of-ranked-5s/)
